# LightBox Gallery

A simple **LightBox Image Gallery** built using **HTML, CSS, and JavaScript**.  
This project includes smooth transitions and a hover effect where images change from **grayscale to normal color**, helping to understand CSS transitions and **Flexbox layout** in a practical way.

## 🌟 Features

- 🖼️ **LightBox Image Gallery**
- 🎨 Images appear **grayscale by default**
- ✨ On hover, images smoothly transition to **normal color**
- 🧭 Clean layout using **CSS Flexbox**
- 🔄 Smooth transition effects
- 📱 Simple and responsive design

## 🧱 Technologies Used

- **HTML** – Structure of the gallery  
- **CSS** – Flexbox layout, hover effects, transitions  
- **JavaScript** – LightBox functionality  

## 🧠 What I Learned From This Project

- Practical use of **CSS Flexbox** for image layouts
- Creating **hover effects** with smooth transitions
- Using `filter: grayscale()` and transition properties
- Implementing a basic **LightBox popup**
- Improving UI interaction using CSS animations
